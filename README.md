# Poster Sprint Studio (v2)
Creative Web Tools midterm. A workspace for daily, coached design practice.

Run: open index.html in Chrome, or `python3 -m http.server` in this folder and visit http://localhost:8000.
Debug: `?speed=60` runs the sprint clock 60x faster. `?reset` clears local settings and challenges. `?demo` turns on demo pieces.
Demo pieces: Settings → "Show demo pieces in archive". These are tagged DEMO and are never exported.
AI feedback: Settings → choose Gemini or Anthropic and paste your own key. It is stored in localStorage only.
Files: index.html, styles.css, js/lessons.js (original, unchanged), js/data.js, js/db.js (IndexedDB), js/critique.js, js/app.js.
